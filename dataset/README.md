# Bộ dữ liệu VIA Cốm

Thư mục này chứa quy cách và các mẫu nhỏ. Dữ liệu lớn không đưa vào git; nơi lưu trữ sẽ được công bố khi có đợt dữ liệu đầu tiên. Xem [docs/DATASET.md](../docs/DATASET.md).

Ghi một phiên trong nông trang ảo:

```bash
python tools/run_sim.py
python tools/record_dataset.py --out dataset/sessions/ten_phien --contributor "Tên bạn"
```
